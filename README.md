# 🌹 Serenata Romántica de Cumpleaños para Nicoin (Chikki) 💖

Sitio web interactivo y romántico de una sola página para celebrar los 26 años de Nicoin ("Chikki"), con todo el amor de Chango.

## Personalización rápida

Edita el objeto `SITE` al inicio de `script.js` si deseas cambiar el nombre, edad, firma o mensajes especiales sin modificar el resto del código:
- `SITE.recipient`: `{ name: "Nicoin", age: 26 }`
- `SITE.signature`: `"Chango"`
- `SITE.publicUrl`: `"https://jhojha.github.io/feliz-cumple-chikki/"`

## Publicar en GitHub Pages

1. Crea un repositorio en tu GitHub llamado `feliz-cumple-chikki` (o el nombre que gustes).
2. Asocia y sube este proyecto a tu nuevo repositorio:
   ```bash
   git remote add origin https://github.com/TU-USUARIO/feliz-cumple-chikki.git
   git branch -M main
   git push -u origin main
   ```
3. En GitHub, ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch** -> `main` / `/(root)` y guarda.

¡Tu novia recibirá su serenata romántica en su propia URL de GitHub Pages! 🌹✨
